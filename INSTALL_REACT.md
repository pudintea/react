# INSTALL REACT VITE
```
npm create vite@latest my-folder-project -- --template react
```

Atau Buat folder project dulu
```
mkdir my-folder-project
```
```
cd my-folder-project
```
```
npm create vite@latest . -- --template react
```
Instal dependencis yang dibutuhkan
```
npm install
```
Runing Dev
```
npm run dev
```

Jangan lupa install Extensen Vscode ES7 by dsznajder untuk bisa mengetikan
```
rafce
```
Install React Router Dom
```
npm install react-router-dom
```

Install React Boostrap
```
npm install react-bootstrap bootstrap
```
import boostrap di main.jsx
```
import "bootstrap/dist/css/bootstrap.min.css";
```
