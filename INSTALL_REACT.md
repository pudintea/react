# INSTALL REACT VITE
```
npm create vite@latest my-folder-project -- --template react
```

Atau Buat folder project dulu
```
mkdir my-folder-project
```
```
cd my-folder-project
```
```
npm create vite@latest . -- --template react
```
Instal dependencis yang dibutuhkan
```
npm install
```
Runing Dev
```
npm run dev
```
